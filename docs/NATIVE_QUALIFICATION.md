# Bind the actual native boundary

The supplied historical CLI is semantic background, not proof of current implementation.
The user reports Min-P/DRY now; current GBNF/samplers/restart behavior must be discovered.
Use existing authorized checkout/context for llm-60. No SSH command, host address, model,
API field, launch command, process kill or GPU allocation is invented in this archive.

Record source revision and dirty content hash, store/model/tokenizer identity, build and
device, native API/CLI control names, terminal/partial receipts, grammar ordering, candidate
mask behavior, seed/DRY/breaker rules, sampler clone/reset/serialize hooks, and request replay.
Record requested and accepted profiles; unknown/ignored arguments are not capability proof.

Capability is granular: parsing a GBNF string, constraining token generation, cloning a
matcher, active-partial CONTINUE, branching that state, serializing it, restarting it,
combining it with each sampler, native GPU execution, and speculative decoding are separate.
Likewise profile acceptance, algorithm numerical correctness and output quality differ.

A public library implementing an algorithm does not establish that the user's COW service
exposes it, stores it or preserves it through fork/rewind. Use primary source references in
SOURCES.md as algorithm context, then pin and test the actual implementation. A static
upstream code view must never substitute for local endpoint discovery.

The native backend owns per-token execution and mutable decoder state. The BW adapter must
pass a frozen profile through a real supported boundary or reject it. No application-side
regeneration/rejection loop, text post-filter or JSON schema adapter can substitute for
native constrained decoding or sampler-state correctness.

Qualify one-service/two-role and two-service deployments separately. A snapshot from one
service is not meaningful on another. A changed endpoint URL does not establish the same
store. A cached context can be unavailable even when logical history remains retained.
Keep real host allocation/lifecycle ownership separate from remembered hardware specs.
