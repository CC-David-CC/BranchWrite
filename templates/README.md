# Typed generators through the same runtime

The seven prompt templates use one-pass substitution of declared slots. Their output
contract is a type-derived non-JSON `.bw` grammar and validator, pinned per invocation.
`source_data_bw` is bounded authorized text, not a JSON object. User/tool data is literal
and cannot recursively introduce template fields. These are declarations to bind in the
actual product, not a second template runtime shipped beside it.

The operation catalogue names standard purposes and typed outputs. Canonical production
types define their exact shape and provenance checks. A prompted ReasoningNote is generated
analysis, not a claim to expose hidden/native reasoning. Native capability must be observed.
