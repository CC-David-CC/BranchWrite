# Three worked BranchWrite tool examples

These examples are hypothetical tasks on different files. They were authored by the host and executed through the real registered tools to check them. They are demonstrations, not current work. In the real task, use only the files named by the live tool schema and the actual current read result. Do not copy example hashes or paths.

A world hash identifies the owned workspace. A source_sha256 identifies exact file bytes. They are different identities. The host binds observation.source_sha256 from the latest actual observation of that same file. Do not put checksum fields in model tool proposals. Preserve the exact before text including spaces and newlines. A rejected plan does not change the file; retain the last valid read until current bytes change.

Each example shows the full file to read, a small exact replacement, actual tests and a finish request. A finish request is not a test result. If tests fail, use their feedback and keep working. No shell, hidden tools, new permissions or modifications to tests are allowed. The same protocol works with different tasks and many support functions.
