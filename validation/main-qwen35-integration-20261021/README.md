# Dense-model client integration

The configured focused regression run passed 120 tests, with no failures or skips.
It covers interactive sessions, saved versions, receipt retry, PDF tools/observations,
tool grammar whitespace, text-file metadata ordering and model-visible errors.
It is not the whole test catalogue or a statement about model task competence.
The server implementation provides the real-model runtime; this client keeps the
same authenticated HTTP and durable-operation mechanisms for Flash and Qwen.
