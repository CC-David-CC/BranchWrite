the server still enforces namespace grants, expiry and original retention.
Temporary client files are private and removed on completion/failure.

## Limits and next work

Trusted self-contained HTML only; arbitrary candidate browser-host OS isolation,
asset/interaction coverage, broader model quality and VC/G qualification remain.
Image input currently enters BranchWrite through `prepare`; its `ask`/append
methods do not yet expose image suffixes. Preserve those explicit limits.

Inspection also found an independent existing CLI bug: BranchWrite `load_context`
writes structured messages to JSON but invokes COW's intentionally plain-text
`load --file`. It therefore changes roles/content into one system string. H02
uses `prepare`, so its actual input audit passes. Fix structured loading with an
explicit CLI option and canonical-message regression before GOLDEN PATH uses it.

allowed) and a separate ongoing GOLDEN PATH branch of verified facts. See
[their implementation plan](../docs/THINKING_AND_GOLDEN_PATH.md). They are not
implemented or timed here. Chat remains off, Q8 deferred, LAN Git only.
