The suite is run with:

```sh
python -m unittest discover -s tests -v
```

The read-only integrity/catalogue check is:

```sh
python tools/verify_handoff.py
```

Its `HANDOFF_VALID` label means the payload hashes, catalogue, syntax examples, profile
shape and planned statuses agree. It does not mean the product has passed acceptance.
The archive is also extracted into a clean directory and these commands are rerun during
release checking. The clean-copy test and example logs are retained in
`fresh-extraction-tests.txt` and `fresh-extraction-example.txt`; generated bytecode caches are not included in the handoff.

## Planned acceptance is separate

There are **339 product acceptance cases: 211 inherited and 128 new**, allocated to
**40 implementation tickets**. Every product case is `not_run` and every ticket starts
`not_started`. The migration table binds old case records to the new representation.
A ported case description is not a newly executed product test. In particular, R35 must
bind/re-express source fixture metadata while preserving its actual data and oracle behavior.

## Not executed or established here

No real BenchWrite repository checkout, native COW operation, GPU inference, real tokenizer,
full GBNF matcher, OS sandbox, actual process overlap, remote execution, Git publication,
power-loss durability, native exact checkpoint restart or end-to-end model quality test was
run. The reference RNG is deliberately its own specified oracle, not a native RNG clone.
The reference code does not implement native DRY, Mirostat 2 or Adaptive-P. State fields
and fork tests cannot prove those algorithms or their serialized feedback are correct.
No latency, tokens/second, useful-work improvement or optimal compute allocation was measured.

The user reported Min-P and DRY available; that remains a report to qualify against actual
native source/build/commands. The remaining controls are unqualified requirements, not
capabilities inferred from the older source handoff. Exact native replay and constrained
speculative/MTP correctness require independent boundary evidence.
